Applied case study - separate from the algorithm package

Tennessee STAR causal discovery: paper replication plus a robust application profile

A reproducible application to the randomized class-size experiment. The report keeps five layers separate: descriptive randomized-arm evidence, literal paper-profile PAG discovery, an independently run R reference, a conservative application profile, and researcher interpretation of selection, discretization, and temporal plausibility.

Cohort and method

Application design

The source contains 11,601 students who participated in at least one experimental year. The analysis starts from the 6,325 students assigned to a STAR class in kindergarten across 79 schools: small classes of approximately 13-17 students, regular classes of 22-25, or regular classes with a full-time aide. All discovery variables are discretized and tested with the likelihood-ratio G-square CI test.

The R API does not expose the explicit k=3 bound used by the local paper profile, so this is a differential implementation comparison, not a claim of identical internal search schedules.

Finite-sample reliability layer

A separate robust FCI+ application profile

This is not a rewrite of Claassen et al. Algorithm 2. The paper profile remains the validation target. For empirical interpretation, the robust profile uses stable depth-wise skeleton deletion, the strongest separating set at each successful depth, conservative collider handling, and cautious endpoint orientation. Every local fit is repeated under all cyclic column shifts.

Same data and statistical decision rule

Computational work across validation and robust profiles

Each full-data fit used identical panel rows, the same compact-table G-square p-values, and α. Standard FCI and the local FCI+ used the Python package; the external result used R pcalg. The robust profile deliberately spends additional CI calls for stability. Runtime across languages is descriptive, while CI-call counts are the more direct work comparison.

Across these small 8-9 node panels, the paper-profile local FCI+ used fewer CI tests than standard FCI in every comparison and reached as little as 16% of standard FCI's median runtime. The R package required more CI calls than the local FCI+ on all three primary fits. This is an empirical application result, not a proof of asymptotic complexity. The polynomial FCI+ guarantee requires faithfulness and a true maximum MAG degree no larger than the supplied k; neither condition can be verified from STAR alone. The robust profile trades part of that speed advantage for order invariance and conservative endpoints.
Researcher self-assessment

What can and cannot be concluded

Supported conclusions

Small-class achievement advantage is visible descriptively.

The randomized-arm summaries show higher kindergarten and grade-3 composite scores for the small-class arm, while the aide arm is close to the regular-class arm.

Grade-3 observation is selective.

All three PAGs connect observation status to socioeconomic/contextual or kindergarten-achievement nodes, while no direct K_Class-Grade3_Observed adjacency is retained in the primary attrition fit.

Achievement persistence is stronger than a direct treatment edge in the full longitudinal panel.

Kindergarten and grade-3 achievement remain adjacent, whereas class assignment is separated after the early achievement node is included.

The focused paper-profile result replicates exactly.

Standard FCI, paper-profile self FCI+, and R pcalg FCI+ return the same ten-edge PAG. The robust profile keeps the same skeleton but leaves the class/grade-3 endpoints unresolved: K_Class o-o Grade3_Achievement.

The local FCI+ reduces search work.

It uses fewer CI calls than both standard FCI and R pcalg FCI+ on every primary STAR panel.

Limits and audit failures

The PAG is not an effect estimate.

Neither FCI nor FCI+ estimates the number of score points caused by a smaller class. The arm contrasts come from the experiment's assignment, not from PAG endpoints.

Paper implementations do not win every plausibility audit.

R pcalg gives the temporally sensible kindergarten-achievement to grade-3-observation direction, while standard FCI reverses it and paper self FCI+ leaves it partly unresolved. In the longitudinal panel, both paper FCI+ implementations reverse the achievement chronology. The robust application profile leaves those directions unresolved. The temporal audit found 3 backward directed edges: Standard FCI (Attrition / observation): Grade3_Observed --> K_Achievement; Self FCI+ (paper) (Longitudinal achievement): Grade3_Achievement --> K_Achievement; R pcalg::fciPlus (Longitudinal achievement): Grade3_Achievement --> K_Achievement.

The treatment-outcome edge is specification-sensitive.

The sensitivity table shows whether the edge survives changes in α, discretization, and the FCI+ sparsity bound k. A conclusion that appears only at selected settings is not treated as robust.

Mixed educational data are approximated as discrete.

Quantile bins make G-square applicable, but bin boundaries discard information and high-order contingency tables can have sparse expected counts. Students are also clustered within schools and classrooms.

Final assessment: the paper-profile self FCI+ is the most auditable and computationally economical validation implementation in this workflow, while the robust application profile is the most reliable local output for empirical interpretation. Neither is a universally correct causal graph. The strongest causal conclusion remains the randomized small-class contrast. For discovery, conclusions supported by all three skeletons and by temporal knowledge are more credible than any implementation-specific endpoint.
