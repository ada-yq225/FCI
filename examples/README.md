# Examples

The examples are grouped by purpose so that user-facing workflows remain
separate from research benchmarks and presentation artifacts.

- `tutorials/`: small, runnable introductions to FCI, PAG semantics, audit
  export, interactive reporting, and the practical FCI+ profile.
- `benchmarks/`: oracle, nonlinear-CI, external-reference, scaling, and visual
  benchmark drivers.
- `showcases/`: audience-specific presentations built from verified project
  results.
- `generated/`: committed HTML snapshots and local outputs produced by the
  benchmark and showcase drivers.

Run scripts from the repository root with `PYTHONPATH=src`. Generated files
default to `examples/generated/`; transient outputs are ignored where
appropriate.
